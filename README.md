# HelaTrade 🇱🇰

Sri Lanka's B2B marketplace MVP.

## Included
- Marketplace homepage
- Supplier discovery UI
- Category browsing
- Sample verified supplier profiles
- RFQ / request-for-quote form
- Seller onboarding UI
- Responsive mobile layout
